# Mayfly
A no-frills RSS reader designed for people who have gigantic lists of feeds. It runs in the terminal and posts from the last 48 hours are highlighted. Aside from those, it surfaces the most recent post from each feed. Someday it might have a gui. Parallelization is in WORKING and time to first response has been minimized.

It comes with some feeds prepackaged in `list.txt`. To change the list, just edit the file. Otherwise should work out of the box. You may need to `pip install feedparser`. NOTE: Links are printed in black-on-black to reduce clutter. To view an article, just click on the empty space next to the ->. The link is there.
